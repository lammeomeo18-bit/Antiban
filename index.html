3. Tạo file BPF

Cấu hình JSON đã được tích hợp sẵn. Bạn không cần chọn file mẫu hoặc dán JSON nữa.

Tên profile tối đa 14 byte UTF-8 để vừa vùng metadata của mẫu BPF.

Sẵn sàng tạo file.

Lưu ý: cấu hình proxy mặc định chọn direct vì không có máy chủ proxy bên ngoài. Việc tạo file thành công không đảm bảo mọi ứng dụng BPF đều hỗ trợ cùng phiên bản cấu hình.
